# BaobabAI Landing Page

This repository contains a Next.js landing page for BaobabAI, an AI agency focused on AI agents and automation for enterprise operations.

## Development

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser to view the landing page.

## Project features

- Next.js App Router
- TypeScript support
- Tailwind CSS styling
- Branded AI agency landing page layout

## Deploying on Vercel

The app is ready to deploy on Vercel with the default Next.js settings. Follow these steps:

1. Push your project to GitHub, GitLab, or Bitbucket.
2. In Vercel, click **New Project** and import this repository.
3. Verify the project settings:
   - Framework Preset: `Next.js`
   - Build Command: `npm run build`
   - Output Directory: leave blank
4. Deploy the project..

Vercel will automatically detect the `app` directory and serve the landing page.
